## API概览
Smart Text Toolkit API 提供10个端点，覆盖开发者日常文本处理需求：
1. **Markdown → HTML** — 标准Markdown转HTML，支持Github Flavored
2. **JSON格式化** — JSON美化/压缩/验证
3. **代码高亮** — 语法高亮(Python/JS/HTML/Java/SQL)
4. **二维码生成** — 文本/URL生成QR码(返回Base64 PNG)
5. **CSV → JSON** — CSV转JSON数组，支持自定义分隔符
6. **文本差异对比** — 行级diff，生成unified diff格式
7. **图片→Base64** — 上传图片转Base64 Data URI
8. **URL缩短** — 短链接生成与跳转
9. **语言支持列表** — 获取支持的编程语言
10. **健康检查** — 服务状态监控
