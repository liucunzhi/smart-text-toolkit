## 产品描述

你是否厌倦了重复的手动文件操作？批量重命名100个文件？CSV转JSON手动复制粘贴？一遍遍查找重复行？

**PySwift Toolkit** 是一套轻量级Python命令行工具集，专为开发者、数据分析师和效率控设计。

### 包含6个工具：

| 工具 | 功能 | 使用场景 |
|------|------|----------|
| `batch-rename` | 批量重命名文件 | 照片整理、项目文件管理 |
| `csv2json` | CSV转JSON | 数据迁移、API对接 |
| `extract-emails` | 从文本提取邮箱 | 客户列表整理、数据清洗 |
| `qr-gen` | 生成二维码 | 营销物料、链接分享 |
| `merge-csv` | 合并多个CSV | 月度报表汇总 |
| `dedup-lines` | 删除重复行 | 日志分析、数据去重 |

### 为什么选择PySwift？
- ✅ **零依赖**（除qr-gen需qrcode库）
- ✅ **单文件运行** — 拷贝即用
- ✅ **源码交付** — 可自行修改定制
- ✅ **Windows/Mac/Linux通用**
- ✅ **详细注释** — 适合学习Python CLI开发

### 使用示例
```bash
# 批量重命名照片
python pyswift.py batch-rename --dir ./photos --pattern "vacation_{n}" --ext .jpg

# CSV转JSON
python pyswift.py csv2json --input data.csv --output data.json --pretty

# 提取邮箱地址
python pyswift.py extract-emails --input emails.txt --unique
```
